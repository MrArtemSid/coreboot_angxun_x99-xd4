# Machinist X99 B9

Board sources are in `machinist/x99-b9/`; original stock-system logs are
in `logs/`. The logs are preserved unchanged.

The board owner corrected the earlier **Angxun X99-XD4** identification
to **Machinist X99 B9**. The old model name and firmware filenames are
not proof of the physical board identity. This correction does not
revalidate inherited GPIO, PCIe, Super I/O or firmware-input settings.

Canonical repository: https://github.com/MrArtemSid/coreboot_machinist_x99-b9

Coreboot development tree: https://github.com/MrArtemSid/coreboot/tree/x99-minimal
